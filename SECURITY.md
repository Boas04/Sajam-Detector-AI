## Melaporkan Kerentanan

Jika Anda menemukan kerentanan keamanan pada proyek ini, **jangan** membuka Issue publik.

Silakan laporkan secara bertanggung jawab melalui salah satu cara berikut:

1. **Email langsung** ke pengelola proyek (lihat profil GitHub [@Boas04](https://github.com/Boas04))
2. **GitHub Private Security Advisory**: Buka tab *Security* → *Advisories* → *New draft security advisory*

### Informasi yang perlu disertakan:
- Deskripsi kerentanan
- Langkah-langkah untuk mereproduksi
- Potensi dampak
- Saran perbaikan (opsional)

Kami berkomitmen untuk merespons laporan dalam **72 jam** dan memberikan update berkala hingga masalah terselesaikan.
